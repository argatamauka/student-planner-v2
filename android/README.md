# Student Planner v2 Android

Folder ini berisi wrapper Android native untuk Student Planner v2.

- Package: `com.argatamauka.studentplanner`
- Minimum Android: 7.0 (API 24)
- Website production: `https://studentplannerarga.vercel.app/`
- Login, data Supabase, jadwal, tugas, keuangan, tabungan, dan profil tetap memakai backend yang sama.
- Pemilihan foto profil didukung melalui Android file picker.

APK debug dibangun otomatis oleh GitHub Actions dan bisa langsung dipasang untuk penggunaan pribadi.
